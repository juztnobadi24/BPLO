# Business Website Design Style

## Design Philosophy

### Color Palette
- **Primary**: Deep navy (#1a2332) - Professional, trustworthy
- **Secondary**: Warm gold (#d4af37) - Premium, success
- **Accent**: Soft gray (#f8f9fa) - Clean, modern
- **Text**: Charcoal (#2c3e50) - Readable, sophisticated

### Typography
- **Display Font**: "Playfair Display" - Elegant serif for headings
- **Body Font**: "Inter" - Clean sans-serif for readability
- **Accent Font**: "Montserrat" - Modern sans-serif for buttons/labels

### Visual Language
- **Minimalist Elegance**: Clean lines, generous whitespace
- **Professional Authority**: Sophisticated color choices
- **Modern Sophistication**: Contemporary layouts with classic touches
- **Trust Indicators**: Professional imagery, clear information hierarchy

## Visual Effects

### Used Libraries
- **Anime.js**: Smooth animations and transitions
- **Typed.js**: Dynamic text effects for hero section
- **Splide.js**: Image carousels and testimonials
- **ECharts.js**: Business data visualizations
- **p5.js**: Interactive background elements
- **Matter.js**: Physics-based hover effects
- **Splitting.js**: Text animation effects

### Effects & Animations
- **Hero Background**: Subtle particle system with p5.js
- **Text Effects**: Typewriter animation for main headline
- **Image Carousels**: Smooth service showcase with Splide.js
- **Scroll Animations**: Reveal animations with staggered timing
- **Hover Effects**: 3D tilt and shadow expansion on cards
- **Form Interactions**: Progressive validation with smooth feedback

### Styling Approach
- **Grid-Based Layout**: Consistent spacing and alignment
- **Card-Based Components**: Elevated surfaces with subtle shadows
- **Gradient Accents**: Subtle gold gradients for premium feel
- **Responsive Design**: Mobile-first approach with fluid scaling

### Header Effect
- **Floating Navigation**: Semi-transparent header with blur backdrop
- **Logo Animation**: Subtle scale and glow on hover
- **Menu Transitions**: Smooth slide-in mobile menu

### Interactive Elements
- **Service Cards**: Hover with depth and information reveal
- **Registration Form**: Multi-step with progress indication
- **Calculator Tool**: Real-time updates with animated counters
- **Testimonial Slider**: Auto-advancing with manual controls

This design creates a premium business aesthetic that builds trust while maintaining modern usability and engaging interactions.
